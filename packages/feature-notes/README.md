# Nook 笔记

笔记是本地知识资料的统一入口。[契约](../capability-note/src/index.ts)定义零或一个项目归属、创建和更新时间、版本号及来源；[业务服务](src/index.ts)检查项目存在性，删除项目时保留笔记并解除归属。

## 使用

主界面通过侧栏的 Nook 入口进入笔记工作区。打开后可直接新建笔记，标题可留空。编辑器支持 Markdown 输入、标题、粗斜体、列表、待办、引用与代码块，支持导出 Markdown。列表提供标题和正文搜索、项目筛选、创建时间/更新时间/标题排序、置顶和分页。删除进入回收站，可恢复。卡片右键菜单提供删除、导出、置顶/取消置顶；回收站卡片提供导出和恢复。键盘可用 Shift+F10 打开卡片菜单，方向键选择、Escape 关闭。

侧栏项目支持直接拖动整行排序，不显示拖动图标；右侧操作菜单入口仅在悬停项目时显示，可通过菜单上移、下移、修改名称与描述、删除项目。顺序持久保存并随项目同步，新项目追加在末尾。删除项目保留笔记并移入“未分类”，当前笔记仍可继续编辑。

导出后右下角显示可关闭提示。桌面端写入系统下载文件夹，同名文件自动编号；点击“打开文件夹”在文件管理器中定位导出文件。网页端使用浏览器下载，提示可在下载列表查看文件，不提供本地文件夹访问。导出包含当前编辑内容，未保存或冲突草稿也可导出。

编辑器右上角的省略号按钮打开操作菜单，提供“历史版本”和“导出”。编辑后自动保存，顶部不显示保存状态文案。保存失败显示错误及重试、另存为新笔记操作，并保留浏览器草稿。并发版本冲突不覆盖服务器内容，可导出或另存为新笔记。浏览器草稿是临时保护，持久副本由本地 Provider 管理。

来源标识区分个人笔记、视频字幕、评论区笔记、AI 整理文稿和 AI 总结。来源链接和作者随笔记保存；AI 派生笔记保留所依据笔记的标识与版本。引用打开当前笔记，版本号用于说明生成时的依据，不提供历史版本回放。修改来源笔记不会自动重写已有 AI 文稿。

## 存储与检索

[本地 Provider](../provider-notebook-local/src/index.ts)接收 `file` 配置，由[产品组合](../app-all/cordis.patch.yml)指定数据库位置。SQLite 保存笔记、检索片段和会话偏好；笔记写入与 FTS5 索引更新在同一事务内。软删除移除索引，恢复重建索引。标题独立于正文也可检索。

检索使用中文字符/双字词和拉丁词的关键词匹配与 BM25 排序，无需 embedding 模型。它适合已有用词的查找，不承诺同义改写的语义召回。替换检索实现应遵循 [Knowledge Capability](../capability-knowledge/src/index.ts)。

跨设备行为和稳定版本标识见[同步契约](../feature-sync/README.md)。

完整快照、删除恢复记录与恢复命令见[备份指南](../../docs/backup.md)。

## 总结

日/周总结入口按本机时区计算日期，使用笔记创建时间选择范围，可进一步限定项目。总结使用 DSH 配置的模型，支持取消、预览编辑和保存为笔记。已有 AI 总结不作为输入，避免反复总结自身。

同一次总结的分批处理和最终合并共用一个模型会话标识，独立总结使用不同标识，以满足模型服务的路由要求。该标识不创建 AI 对话或持久化 DSH 会话。

模型认证、额度、请求限流、连接异常、上下文超限及输出不完整会显示对应原因和处理建议。提示由 Nook 生成，不直接展示服务商原始响应。失败或取消不会保存部分总结，原笔记保持不变，可调整范围或模型后重试。

[总结服务](../feature-reflection/src/index.ts)分段处理资料，超过 500 条候选笔记或 18 万字时要求缩小范围。生成结束前检查来源版本，资料变化时提示重试。模型效果需要人工判断，预览不会自动入库。
