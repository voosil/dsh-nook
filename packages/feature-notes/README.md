# Nook 笔记

笔记是本地知识资料的统一入口。[契约](../capability-note/src/index.ts)定义零或一个项目归属、创建和更新时间、版本号及来源；[业务服务](src/index.ts)检查项目存在性，删除项目时保留笔记并解除归属。

## 使用

主界面通过侧栏的 Nook 入口进入笔记工作区。打开后可直接新建笔记，标题可留空。编辑器支持 Markdown 输入、标题、粗斜体、列表、待办、引用与代码块，支持导出 Markdown。列表提供标题和正文搜索、项目筛选、创建时间/更新时间/标题排序、置顶和分页。删除进入回收站，可恢复。

编辑后自动保存；“已保存 · 已入库”表示服务器保存及索引事务完成。保存失败保留浏览器草稿。并发版本冲突不覆盖服务器内容，可导出或另存为新笔记。浏览器草稿是临时保护，持久副本由本地 Provider 管理。

来源标识区分个人笔记、视频字幕、评论区笔记、AI 整理文稿和 AI 总结。来源链接和作者随笔记保存；AI 派生笔记保留所依据笔记的标识与版本。引用打开当前笔记，版本号用于说明生成时的依据，不提供历史版本回放。修改来源笔记不会自动重写已有 AI 文稿。

## 存储与检索

[本地 Provider](../provider-notebook-local/src/index.ts)接收 `file` 配置，由[产品组合](../app-all/cordis.patch.yml)指定数据库位置。SQLite 保存笔记、检索片段和会话偏好；笔记写入与 FTS5 索引更新在同一事务内。软删除移除索引，恢复重建索引。标题独立于正文也可检索。

检索使用中文字符/双字词和拉丁词的关键词匹配与 BM25 排序，无需 embedding 模型。它适合已有用词的查找，不承诺同义改写的语义召回。替换检索实现应遵循 [Knowledge Capability](../capability-knowledge/src/index.ts)。

备份前停止 Nook，然后复制整个运行目录中的 `nook` 子目录，保留项目文件、数据库及其相关文件。项目存储与笔记数据库是独立文件；项目删除先解除笔记归属，失败时不会删除正文。

## 总结

日/周总结入口按本机时区计算日期，使用笔记创建时间选择范围，可进一步限定项目。总结使用 DSH 配置的模型，支持取消、预览编辑和保存为笔记。已有 AI 总结不作为输入，避免反复总结自身。

[总结服务](../feature-reflection/src/index.ts)分段处理资料，超过 500 条候选笔记或 18 万字时要求缩小范围。生成结束前检查来源版本，资料变化时提示重试。模型效果需要人工判断，预览不会自动入库。
