# Nook 数据同步

同步运行于每台设备的本地 Host。工作区侧栏的“数据同步”用于填写 WebDAV 专用目录、存储用户名和密码或应用令牌，验证连接并开启同步。各设备填写同一目录；Nook 不需要产品账号。默认关闭，笔记保存及搜索无需连接存储。

同步弹窗提供“部署家庭服务器 / 查看 NAS 配置指南”入口，点击进入独立的 `#nook-sync-guide` 页面；返回后保留未提交的配置。页面默认提供[家庭服务器安装助手](../../docs/sync-server.md)，其他部署方式和 NAS 说明位于展开项中。系统安装工具的范围和维护方式见[工具说明](../../scripts/sync-server/README.md)。

## 范围与状态

笔记和项目参与同步，包含正文、标题、置顶、时间、回收站、来源和项目归属。AI／视频内容保存为笔记后按同一规则处理。SQLite 文件、FTS 和切片不上传，接收笔记时在本机更新索引。独立产物、原始音视频、DSH 对话、模型配置、知识会话偏好、浏览器草稿与本地备份不上传。Markdown 外链保持原值，本机路径不会转换为可跨设备访问的附件。

编辑器的“已保存到本地 · 已入库”表示本地事务完成；侧栏另行显示等待、进行中、失败、冲突及完成状态。“已同步”表示最近一次远端对账完成且当前无待发版本，不表示其他设备已经接收。离线修改保留在 SQLite，关闭同步不清除待发版本或本地内容。

本地变更约 1 秒去抖后尝试同步；启动及手动操作可立即触发，正常运行每 30 秒检查。失败按指数退避并加入随机延迟，上限约 6 分钟。每个 Host 串行运行同步；关闭或卸载会取消请求和定时器。同机网页和桌面复用[共享 Host](../../docs/runtime.md)。工作区每 3 秒检查本机变化，刷新列表和未编辑的正文；有未保存输入时保留草稿并提示变化。

## 冲突与恢复

版本以父版本关系判断先后，不比较设备时钟。并发修改保留分支，冲突入口可选择某个版本，或将其他版本保存为独立副本。解决结果引用当前全部冲突头，过期的解决请求会被拒绝；重试传输不会重复创建副本。笔记删除使用回收站标记，删除与编辑也可以产生冲突。

项目、笔记及同步元数据共用本地 SQLite 事务。项目删除保留正文并解除归属；远端项目删除与离线新增笔记相遇时，本机把不存在项目下的笔记归入未分类，并停用该项目的知识会话。原归属保留在版本及恢复记录中。不同记录分别判断冲突，项目冲突不保证关联笔记作为一个冲突组一起解决；项目副本也不会自动复制全部关联笔记。

启用前创建并校验完整业务数据备份；远端替换、删除、解除归属及冲突处理前写入并校验恢复记录，失败则回滚落地事务。备份位置和恢复操作由[备份指南](../../docs/backup.md)定义。备份与远端历史不自动清理。

本机首次连接后绑定目标地址及远端库 ID。目标索引消失、库 ID 改变、索引代数回退或已见历史缺失时停止同步，不清库重下。切换目录需要独立本地库；仅修改同一目标的凭据可以重新验证。恢复较早的本地完整备份后可继续与同一远端对账，离线分支按冲突处理。不要手工编辑远端协议文件。

## WebDAV 要求

远端必须支持 MKCOL、GET、PUT、DELETE、强 ETag、原子 `If-None-Match: *` 创建和原子 `If-Match` 更新，并原样保存上传字节。配置验证会创建临时探测对象，测试两个竞争写入者只能有一个成功，再删除探测对象。已有业务对象不会被探测清理。短暂弱 ETag 会重新读取至多 3 次，仍不具备强 ETag 的目标拒绝条件写入。应用不把弱 ETag 转换为强 ETag，也不降级为无条件覆盖。

非本机地址要求 HTTPS；可在“服务器 CA 证书”中填写部署工具生成的公共 CA 证书，该信任仅用于当前同步连接，仍校验主机名、证书链与有效期，不修改系统信任或关闭证书验证。公开可信证书保留此字段为空。认证使用 Basic 用户名和存储密码／令牌，不支持 Digest、交互式 OAuth 或重定向。同步目录的上级目录须预先存在。WebDAV 服务或代理配置更改后应重新验证，有限探测不能证明服务在所有负载下的行为。

[独立服务测试](../../tests/helpers/apache-webdav.mjs)使用 macOS Apache 2.4.62、mod_dav_fs、prefork 单工作进程与关闭 KeepAlive 的隔离配置。该测试只监听回环地址；公网部署需自行配置 HTTPS、认证、权限及同等写入串行性。不能从此测试推断多工作进程、NAS 或网盘配置兼容。WsgiDAV 4.3.5 的文件 Provider 在实测中对同一秒内的等长更新复用 ETag，未通过验证，不列为可用目标。其他实际存储服务的兼容性为 UNKNOWN。

## 通用协议与扩展

[Capability](../capability-sync/src/index.ts)定义格式、校验、存储接口及 Host 类型注册；[副本存储](../storage-sync/src/index.ts)拥有版本和事务；[同步引擎](src/engine.ts)只处理通用记录及二进制引用；[WebDAV Adapter](../adapter-sync-webdav/src/index.ts)处理 HTTP；[DSH Adapter](../adapter-sync-dsh/src/index.ts)只暴露设置、状态和冲突操作。业务 Feature 通过 Capability 接入，不依赖 WebDAV 或具体 Provider。

远端布局为 `index.json`、`objects/<sha256>` 与 `blobs/<sha256>`。格式 1 的索引包含库 ID、十进制字符串代数及 `type/id → 当前版本哈希数组`。版本包含类型、稳定记录 ID、类型 schema、父版本、删除标记、JSON 载荷及文件引用；其规范化 JSON 字节的 SHA-256 是稳定版本 ID。文件按原始字节哈希定位，包含字节数和媒体类型的引用随记录传输。

本地保存将业务数据和不可变待发版本一起提交；接收先下载并验证历史和文件，再事务性合并远端基线与业务投影。发布先上传并核验依赖，最后条件替换索引。竞争失败重新读取并合并；响应丢失通过已发布版本的祖先关系确认。确认针对捕获的版本集合，发送中继续编辑不被旧确认清除。没有业务变更时仍读取索引，但不重复下载已有对象。

新增类型通过 `nookSyncReplica.registerType` 注册名称、schema 和同步校验器，用 `records(type)` 读取，用 `writeRecords` 携带期望版本批量写入，注册返回的 disposer 归插件生命周期管理。省略 `apply` 可直接以通用记录作为存储；可选的同步 `apply` 仅用于事务内的本机派生投影，不得提交独立数据库、网络或异步副作用。外部通知通过提交后的订阅发送。二进制先经 `receiveBlob` 验证并持久保存，记录才能引用。可选 `copy` 定义此类型的冲突副本语义。

未知类型或较新的类型 schema 原样保留并继续转送，界面显示升级提示；注册相应处理器后下一轮对账可生成投影。不支持的协议 format 拒绝接收。业务新增字段应升级类型 schema，避免旧处理器丢弃字段。笔记的 `revision` 仍是本机乐观锁，`versionId` 是跨设备内容版本；新生成的来源引用可以带 versionId，旧引用不伪造缺失历史。

索引和单版本对象上限各 4 MB，索引至多 10,000 条记录，每条至多 64 个冲突头或父版本，每个版本至多引用 100 个文件，单文件至多 20 MB，单次历史遍历至多 100,000 个版本。首次同步需要下载可达历史和文件，索引按整体读写；没有分页、历史压缩或垃圾回收，不适合无限增长的数据集。达到限制时停止推进并保留本地数据。

## 配置与隐私

同步设置支持导入部署工具生成的 `connection.json`，或粘贴其 JSON 内容及安装助手输出的 `NOOK-SYNC-1:` 前缀 Base64 UTF-8 文本。编码只用于交接，不提供加密；解析允许复制时的换行，解码后复用相同的严格字段校验。当前文件格式为 `format: "nook-sync-connection"`、`version: 1`，包含 `url`、`username`、`password` 和 `caCert` 四个字符串字段；兼容仅含这四个字段的旧版导出。解析器拒绝未知字段、未知版本、超限内容及夹带凭据的 URL，最大文件大小为 32 KB。导入只填充表单，不连接服务器或保存设置；用户核对目标并点击“验证并开启同步”后复用现有 Host 校验、备份与同步流程，实际 CA 解析和 TLS 校验仍在 Host 执行。文件包含明文凭据，不上传为同步数据或记录到日志。

[产品 Profile](../app-all/cordis.patch.yml)在 notebook Provider 设置 `projectsFile` 后启用统一存储；旧 projects.json 一次性导入 SQLite 并保留原文件，迁移回执和初始版本在同一事务提交。未设置该选项的独立 Provider 保留原有笔记能力。目录级迁移的限制见[正式运行环境](../../docs/runtime.md#导入仓库中的旧数据)。

同步 Host 配置的 `file` 指向 `DSH_HOME/nook-sync/settings.json`，保存开关、URL、用户名、密码和可选 CA 公共证书，权限为 0600。密码不出现在状态 RPC、同步记录或业务备份中；客户端仅知道是否已有密码，留空保留已有值。该私有文件不在 `nook/` 业务备份范围，恢复后需重新配置。传输有 TLS，存储内容和本地备份没有端到端加密；存储管理员能读取正文。
