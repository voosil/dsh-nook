# AGENTS.md — 文档标准

本文件定义 Nook 的文档分层、写作规则与检查方式,借鉴 DeepSeek Harness 上游的文档管理体系([docs/AGENTS.md](https://github.com/deepseek-ai/deepseek-harness) / `.agents/notes/README.md` @ `0.1.1-rc.2`,已按个人项目规模裁剪)。放置与校验工作流见 [dsh-docs skill](../.agents/skills/dsh-docs/SKILL.md)。

## 分层:一个事实只有一个家

每条事实只属于一个 tier,即它的"家";在其他任何地方只链接,不重述。改动事实时只改它的家。

| Tier                               | 职责                                                       | 不属于这里的内容                           |
| ---------------------------------- | ---------------------------------------------------------- | ------------------------------------------ |
| 根 `AGENTS.md`                     | 常设指令:每个会话都需要在场的规则,每条 1–3 行,链接到它的家 | 叙述、长流程、任何已链接 home 已承载的内容 |
| [architecture.md](architecture.md) | 结构地图:Profile 组成、Capability 映射、边界决策           | 类型定义、包级细节、决策依据(→ Agent Note) |
| [discovery.md](discovery.md)       | DSH 外部事实:已核实值 + `UNKNOWN` 清单 + 兼容性决定        | 产品设计、需求                             |
| 包 README(按需)                    | 包契约:配置、语义、限制、扩展点                            | 其余包的关注点                             |
| [Agent Notes](../.notes/AGENTS.md) | 决策记录:为什么、放弃了什么、怎么验证                      | 现状描述(→ 上面的 tier)                    |
| `.notes/wip/`                      | 草稿与原始想法,自由格式,不受本规范约束                     | —                                          |

放置口诀:现状 → `docs/`;依据与过程 → `.notes/`;外部事实 → `discovery.md`;包契约 → 包 README。

## 写作规则

- **写现状,不写历史。** 禁止 "previously / now / no longer / 改成了";命名当前机制,变更叙事只进 Agent Note 或 commit message。
- **状态不进正文。** "已实现!"、"future:" 之类标注会腐烂;状态由笔记的生命周期目录承载。
- **相对 Markdown 链接交叉引用**,不用裸文件名或笔记编号;`pnpm docs:check` 会拒绝失效目标。
- **每篇文档只讲自己的主题。** 对直接下级只描述目的、职责与高层行为,细节链接到归属文档。
- **单文档单语言**,同一篇内不混写。
- **段落单物理行**(编辑器软换行;prettier 校验格式)。

## Slop 检查清单

写完或审阅任何文档时过一遍:

- 同一条规则在多处出现 → 留一个家,其余改链接。
- 叙述历史或"战斗故事" → 改为现状陈述,依据链接到 Agent Note。
- 手抄清单/目录(源码或配置才是权威) → 删掉,链接过去。
- 推理过程记录(怎么一步步做出来的) → 留结论与依据,删过程。
- 段落墙(一段塞多条规则加括号补充) → 拆分,细节降级到它的家。
