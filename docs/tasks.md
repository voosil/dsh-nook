# 任务与想法提炼

工作区的“任务与日程”入口打开统一任务页。“待处理”集中展示需要决定的提案、人工待办、验收结果和异常；“计划与清单”支持顺序调整；“日历与日程”支持周、月及日程列表。任务可以拖入日期安排，也可以移除安排，原任务和历史保留。键盘可用上下移按钮调整清单顺序。

## 开始使用

在“任务设置”中选择“使用这台设备执行”，保存后由这台主机裁决任务操作。根据需要选择规划、执行、验收模型，增加专项角色和工作目录。模型角色是显式配置，不根据模型名称推断能力；工作目录属于执行主机，项目分类与代码目录互相独立。默认最多同时运行三个 Agent 作业，同一目录的写入作业串行。

“新建任务”默认保存为个人待办。交给 Agent 后，填写目标和验收标准，内容齐备的任务进入队列；范围、约束和来源可继续补充。有未来开始时间、未满足的依赖或模糊时段时等待。对话可通过同一业务工具创建、调整和查询任务，回执给出状态与详情链接。自由笔记和未确认提案不会触发执行。

新建或编辑任务时，可展开“计划与依赖”，手动建立计划、指定所属计划和前置任务。任务详情展示执行方案、来源版本、每次运行、产物和历史。运行中的目标或范围修改会停止旧执行，并保留其固定版本，确认后再继续。外部执行的领取撤销不代表外部进程已经停止，页面要求核实。

## 时间与恢复

提醒用于通知，开始时间控制执行，截止时间表达完成约定；日程时段可另设结束时间。“上午”等表述可以保存在模糊时段字段，精确执行前需要补齐。所有精确时间带明确时区，日历按当前设备时区展示。

重复安排支持每日、每周及选择星期，规则和每次实例分开保存。修改规则不改写已生成实例；后台恢复只补最近一次。夏令时不存在的本地时刻跳过，重叠时刻取第一次。一次性执行在截止前补跑，截止后进入需介入。提醒逾期仍保留，桌面端将同批可行动事项合并通知。

关闭原对话不影响任务。指定执行主机开启“保持后台运行”后，关闭桌面窗口继续服务；显式退出应用会停止后台。网页入口与后台的生命周期见[运行指南](runtime.md#启动与退出)。休眠期间不执行，恢复在线后按上述规则补处理；不提供开机自启或云端离线执行。

## 提案与计划

任务设置中勾选需要提炼的笔记或项目。连续编辑安静两分钟后合并处理，持续编辑最多十分钟形成一批。“整理想法”可手动触发。首次建立理解，后续只处理成功基线与当前版本之间的变化，并提供必要原文、主题摘要和关键词召回材料。改写、删除、否定及同步合并均参与理解；格式变化跳过语义生成。失败或生成期间来源发生变化时不推进基线。

同主题维护草案，有明确建议后进入待评审。卡片默认显示推荐方案、范围、后果和需要决定的内容；“按此推进”绑定当前提案及来源版本，“补充一句”让规划继续整理，“暂缓”保留原因。实质内容未变化不重复提醒。获批方案与来源版本固定，后续相关变化产生关联的变更提案，既有批准不会自动应用于新方案。

批准后建立计划与带依赖的子任务。子任务技术检查通过后可为后续任务提供产物，计划整体汇总验收，用户无需逐项确认工程任务。执行记录和复盘材料保留为后续理解的依据。

## 验收

AI 验收默认关闭：Agent 提交实际产物和工程检查后，由用户确认；人工任务可以直接完成。开启 AI 验收后，独立验收者根据固定要求检查实际产物，通过即可完成。执行总结仅为辅助证据，产品与界面验收独立于工程测试。

无法访问、无法判断、范围冲突或需要扩大范围时进入需介入。原范围明确缺陷最多自动返工两轮，每轮保留证据与复验结果。验收绑定产物修订；本地文件在验收前后核验内容哈希，文件变化要求重新提交。远端产物应使用不可变版本入口，验收者需读取实际内容。

## 多设备与数据

其他设备的操作先保存到本机，显示“等待执行主机确认”；主机处理后返回“已生效”或冲突。请求 ID 用于去重，领取凭据绑定具体运行；重复请求、过期凭据及失联回报不会覆盖当前结果。后台中断后先核对持久结果，无法确认的任务需介入，不自动重复执行。

同步启用时，首次主机归属通过同步存储原子确认；同一同步库只允许一个执行主机。主机重启后需要连接同步存储确认归属，确认成功后可在本次运行中继续离线工作。同步冲突或归属无法确认时暂停后台作业，其他设备继续保存请求等待。主机归属不自动迁移，不能复制设备身份文件来更换主机。同步布局见[同步契约](../packages/feature-sync/README.md#通用协议与扩展)。

任务、提案、来源理解、运行、验收、通知、请求和回执使用笔记库的版本化副本存储，纳入[备份](backup.md)。任务中的本地文件入口不会自动上传产物。设备身份保存在执行主机的私有 home，MCP 连接文件包含本机凭据，不参与同步。历史不自动删除。

外部接入方式见[MCP 接口说明](../packages/adapter-task-mcp/README.md)，接口与默认值以[任务能力](../packages/capability-task/src/index.ts)为准。
