# 验证入口约束

本目录只承载仓库工程规则检查，以及需要构建、打包准备的验收命令入口。测试分类、运行环境和资源管理遵循 [tests 规则](../../tests/AGENTS.md)；验收证据原则归属 [根规则](../../AGENTS.md)。

- 文档链接、依赖边界、版本固定、发布约束和色值集中管理属于可直接检查的工程约束。检查这些约束可以读取源码与配置，但不得声称由此证明产品功能可用。
- 产品行为断言、浏览器场景和运行环境实现放入 `tests/`。本目录不得导入测试场景或测试辅助设施。
- 验收入口通过 [统一调度器](../test/run.mjs) 执行具名测试，只做准备和编排，不直接调用业务场景函数。
- 聚合命令复用本次准备结果，同一执行组只执行一次。失败必须传播为非零退出码；不得用全部跳过替代成功。
