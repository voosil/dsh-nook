# Agent Note: 家庭同步部署的实机证据记录

Status: implemented

## Problem

容器验收无法发现用户机器的 SSH 权限、代理、软件源和交互登录问题。后续让 AI 在 DSH 对话中协助部署，需要真实环境证据，以及能区分机器操作与用户账号授权的执行流程。

## Decision

部署沿用[家庭服务器安装助手](../feature/2026-09-09-sync-assistant.md)，以 SSH 预检、固定产物核验、依赖安装、设备授权、服务验收和私密交接为连续步骤。执行中持续维护[脱敏实录](../../wip/2026-09-09-home-sync-deployment.md)，实录保留操作证据与未验收项，后续 skill 从中提炼流程。密码、私钥及设备授权链接不进入仓库。

用户给出服务器并要求安装即授权常规安装和配置；账号登录需要用户完成。存在业务容器的宿主机不默认重启，启动顺序检查与整机重启验收分别报告。现有用户数据的任何删除或覆盖均遵循[备份规则](../../../docs/backup.md)。

## Alternatives considered

**直接把已有一行命令当作实机部署结果。** 这无法证明下载入口可达、SSH 身份有效或设备登录完成，因此必须执行并逐步核查。

**遇到摘要差异就换用下载站的摘要继续运行。** 同一来源的文件与校验和不足以解释本地固定值的差异。本次先验证 Windows 换行转换的影响，再用隔离 LF 构建复现公开摘要。

**为下载修改全局代理或重启 Docker。** 服务器承载其他业务，因此先使用已有本机代理的进程级环境变量。镜像下载通过现有 Docker 守护进程完成。

## Consequences

实录包含可复用的故障分支与验收边界，不能把尚未完成的设备授权、客户端接入或宿主机重启标记为成功。通用部署契约继续由[家庭服务器指南](../../../docs/sync-server.md)承载；个别机器的执行结果留在实录。
