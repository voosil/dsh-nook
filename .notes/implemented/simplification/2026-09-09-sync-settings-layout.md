# Agent Note: 同步设置弹窗精简

Status: implemented

## Problem

同步设置将部署入口、导入方式、手动凭据和数据说明并列铺开，重复文案与未启用操作占据首屏，使连接配置缺少清晰主次。

## Decision

数据同步位于[全屏设置](../feature/2026-09-10-appearance-settings.md)的右侧面板，使用“同步信息”和“配置”两个 tab，初次进入展示同步信息。未配置目标时，信息页展示说明与“去配置”主按钮，直接打开 [AI 配置草稿](../feature/2026-09-09-ai-sync-deployment.md)。已有目标时展示保存的地址、最近同步、待传版本和冲突，提供立即同步与开启、关闭操作；关闭同步保留已配置目标，不退回首次配置空态。

设置使用全屏外框、可滚动活动面板和固定底部操作，切换 tab、展开凭据及导入配置时不改变外框尺寸。状态概览、连接卡片和帮助入口使用共享 kit tokens。

连接导入、手动输入、账号与证书、数据保护说明及“配置指南”入口集中在配置 tab。切换 tab 与指南往返保留表单草稿；保存并完成同步后返回信息页。信息页操作使用已保存目标，不采用配置页未保存的输入。异步操作绑定组件生命周期，AI 对话往返的状态与弹窗生命周期见[工作区状态保留决策](../bug-fix/2026-09-11-notebook-navigation-state.md)。

该调整延续[安装助手](../feature/2026-09-09-sync-assistant.md)的连接交接方式，不改变同步协议及备份机制。

## Alternatives considered

将手动输入保留在默认页会让查看状态也需要面对配置表单，因此按查看与配置拆分。隐藏所有手动配置入口会阻碍已有服务接入与故障处理，因此保留配置 tab 及其指南。

只缩短文字仍会保留并列的入口和无效按钮，无法改善操作层级。删除数据保护说明会损失同步范围信息，因此保留为展开项。

## Consequences

首屏聚焦同步状态，手动配置按需进入。浏览器验收覆盖默认 tab、未配置时直达 AI 草稿、键盘切换、指南往返、文件导入、粘贴、配置后返回信息页、保存目标与未提交表单隔离，以及关闭和重新开启同步。

类型检查、构建、契约与同步导入集成测试通过，真实 Host 的干净安装浏览器验收通过，并检查未配置空态与配置表单截图；完整验证结果见 [AI 配置笔记](../feature/2026-09-09-ai-sync-deployment.md#validation)。
