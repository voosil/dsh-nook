# Agent Note: 同步设置弹窗精简

Status: implemented

## Problem

同步设置将部署入口、导入方式、手动凭据和数据说明并列铺开，重复文案与未启用操作占据首屏，使连接配置缺少清晰主次。

## Decision

弹窗使用紧凑宽度，标题旁显示状态，连接导入独立分组。账号与证书、同步范围与数据保护按需展开；部署入口缩为底部配置指南。未开启时只显示验证开启操作，已开启时提供保存配置、立即同步和关闭同步。保留导入凭据敏感性提示与原有配置验证流程。

该调整延续[安装助手](../feature/2026-09-09-sync-assistant.md)的连接交接方式，不改变同步协议及备份机制。

## Alternatives considered

只缩短文字仍会保留并列的入口和无效按钮，无法改善操作层级。删除数据保护说明会损失同步范围信息，因此保留为展开项。

## Consequences

首屏聚焦连接信息与目标目录，详细说明需要展开阅读。浏览器验收沿用真实 Host 与测试 WebDAV，覆盖指南往返、文件导入、粘贴、开启及关闭同步；类型检查、构建与干净安装包验证用于检查交付产物。

本次类型检查、构建、包边界、格式和文档检查通过，所选测试中 15 项通过、1 项外部 Apache 验收跳过，3 项服务器安装测试因 Windows 的 `python3` 启动权限失败。独立浏览器使用模拟接口验证桌面、390px 窄屏、凭据展开及开启关闭操作并检查截图。真实 Host 浏览器验收因缺少开发 Profile 无法启动；干净包安装因依赖镜像 DNS 超时未完成，不能视为完整发布验收通过。
