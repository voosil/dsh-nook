# Agent Note: Nook 界面统一使用图标库

Status: implemented

## Problem

字符和字体字形充当图标时，外观、对齐和粗细受系统字体影响，界面识别方式不一致。用户要求 Nook 图标使用图标库。

## Decision

Nook 的导航、编辑器工具栏、置顶标记、链接和入口使用 Lucide React 的具名 SVG 组件。各界面包声明直接依赖，构建器只打包使用的组件，React 继续由现有 Client 加载器提供。界面约定见[架构文档](../../../docs/architecture.md)。

有文字标签的图标对辅助技术隐藏；纯图标按钮具有中文无障碍名称和提示。笔记列表的置顶标记提供“已置顶”名称。

## Alternatives considered

保留字符图标并固定字体：仍依赖字体字形，也不满足用户要求。

自绘 SVG 或引用官方界面内部图标：增加维护成本或依赖私有组件；公开图标库可直接满足需求。

## Validation

类型检查与构建验证组件导出及打包；现有契约、集成、Profile 与全新安装验收验证 Client 加载及笔记操作。浏览器验收使用中文按钮名称定位，避免将装饰字形作为操作契约。

## Consequences

三个界面包增加精确版本的图标库依赖，客户端包包含所用 SVG。后续界面图标沿用同一库及无障碍约定。
