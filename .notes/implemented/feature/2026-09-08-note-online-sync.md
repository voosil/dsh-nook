# Agent Note: 通用个人数据同步

Status: implemented

## Problem

Nook 面向个人的开源产品需要跨设备接续工作，不需要 Nook 账号或多租户系统。使用者明确指出数据范围会超出笔记；同步方案必须能接入结构化实体及文件，同时保留离线编辑、并发分支和删除前恢复能力。

此决策扩展[最小产品](2026-09-07-minimal-nook.md)的本地存储范围，同机入口复用仍由[共享运行环境](../architecture/2026-09-08-shared-runtime.md)负责。

## Decision

采用本地 SQLite、通用记录版本图、独立内容寻址文件和可替换存储 Adapter。WebDAV 是首个目标，笔记及项目是首批消费者。Feature 依赖 Nook Capability，各类型承担校验及投影语义，未知类型保留。公开格式、扩展接口、使用方式和限制的唯一说明位于[同步契约](../../../packages/feature-sync/README.md)。

不可变对象配合条件更新的有界索引，使轻量存储端不承担业务逻辑。按记录的祖先关系判断并发，避免设备时钟和本机 revision 被误用为全局版本。索引发布保存一个完整的元数据视图，记录冲突独立保留；不承诺跨记录的自动语义合并。

笔记、项目与待发版本共用事务，以避免业务写入成功而同步记录丢失。迁移保留旧项目 JSON，应用远端内容先执行恢复保护。凭据属于 Host 私有配置，不引入账号体系。完整数据库的目录迁移保留同步历史，两个不同同步库的文件级自动拼接拒绝执行，以免混合绑定和基线。

同步弹窗仅保留指南入口，操作步骤由独立路由页面承载，避免部署说明占用配置表单。Linux 一键部署和连接专用证书信任由[部署工具决策](2026-09-09-sync-server-setup.md)负责。

## Alternatives considered

**Supabase。** 数据库事务有价值，但个人开源定位不需要原推荐依赖的账号及多租户能力。让使用者维护数据库项目和后端函数比复用现有个人存储更重，因此不作为默认方案。

**S3 兼容存储。** 适合已有存储桶的用户，条件写入也适合此协议。首版集中验证一种目标；S3 的 endpoint、bucket、region、密钥及厂商语义留给独立 Adapter。

**专用同步服务器。** 可以用一个实例与令牌服务单人，不必有用户表；它能集中事务处理，但增加部署要求。当前把协议封装在 Host，引入服务端时可保留业务 Capability。

**Obsidian 风格的文件库。** Markdown 文件适合直接编辑和文件同步；Nook 的知识索引及未来多种结构化数据需要明确类型与关系，因此借鉴本地优先及可替换目标，不强制所有实体成为 Markdown 文件。

**整库 SQLite／网盘快照。** 适用于备份，无法合并两台设备的离线分支。上传活动数据库主文件还会涉及 WAL 一致性；业务同步不传输 SQLite 文件。

**全局不可变提交链。** 能保存变更批次的全局顺序，但个人应用首批实体无需服务器式全局事件重放。采用有界索引与独立记录历史降低首版复杂度，同时接受索引整体读写和首次历史下载成本。

**忽略条件请求差异。** 独立 WebDAV 测试直接发现 ETag 和并发语义差异。无条件覆盖不能提供分支保护，因此连接探测拒绝不兼容目标，运行中也保留强 ETag 要求。

## Validation

[契约测试](../../../tests/contract/sync.test.ts)覆盖并发编辑、丢失确认、发送中继续编辑、未知类型及 schema、二进制依赖、索引回退、对象损坏、备份失败和类型注册后的原子批量写入。[HTTP 集成](../../../tests/integration/webdav-sync.test.ts)覆盖真实 notebook 迁移、项目归属、回收站、冲突副本、索引更新、凭据隔离、卸载及独立 Apache mod_dav 双副本对账。

[迁移测试](../../../tests/contract/migration.test.ts)验证完整同步库搬迁与不同历史拒绝拼接。[浏览器验收](../../../scripts/verify/notebook-smoke.mjs)通过完整 Host 设置同步、等待完成及关闭；链接 Profile 和干净 tarball 安装复用同一流程。E2E 使用独立临时数据目录，不在使用目录开启测试同步。指南验收覆盖独立路由、返回时保留配置输入、可复制的一行命令和窄窗口布局，并检查实际安装包截图。

## Consequences

新增数据类型可以复用同步基础，不要求为每种类型重写传输与重试。类型投影及关系修复仍属于业务存储职责；独立产物和原始音视频尚无同步消费者，通用文件机制的存在不等于这些内容已经同步。

索引有容量上限，历史与恢复记录持续增长，无自动回收。WebDAV 目标需要逐项验证，有限连接探测不是普遍兼容性证明；服务部署和数据规模限制以同步契约为准。该方案不提供实时协作、端到端加密或远端用户权限系统。正文自动合并及历史恢复由[自动合并决策](2026-09-10-automatic-sync-merge.md)定义。
