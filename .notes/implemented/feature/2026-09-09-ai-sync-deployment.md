# Agent Note: AI 同步配置与私密导入

Status: implemented

## Problem

家庭服务器部署成功后仍要求用户传输连接文件、填写表单和验证，无法让 AI 连续完成接入。实机部署还发现 Windows 换行破坏固定摘要链，以及安装器通用错误掩盖系统服务依赖问题。证据保存在[实录](../../wip/2026-09-09-home-sync-deployment.md)。

## Decision

同步配置指南以“让 AI 帮我配置”为入口，通过固定 DSH 的公开 Session Controller 和 Conversation 输入接口创建独立草稿，由用户发送。任务说明先从用户表述确定接入、部署或排障，需求不明确时简短询问，随后只获取该路径下一步需要的信息；已确定范围内连续推进，账号授权和系统提权由用户完成。接口核实结果由[发现文档](../../../docs/discovery.md#product-rpc-and-client-contracts)承载。

干净浏览器验收发现，没有工作区绑定的会话会显示禁用的输入框。入口先通过 Nook RPC 准备专用部署目录，用公开 Workspace Controller 幂等注册工作区，再将新会话绑定到它；因此首次使用不依赖用户已有会话或手动目录选择。

AI 工具以 Nook Sync Capability 为依赖，按运行时服务存在与否贡献四个工具并清理。Host 文件导入采用绝对路径和预期 URL，不把密码放入 Tool 参数；正常 Feature 的目标绑定、备份、TLS 与条件写入验证保持为唯一执行路径。配置导入与完成同步分别验收，工具不把“导入成功”当作“已经同步”。

通用任务说明与技术指南分离；“复制提示词”和内置对话使用相同内容，构建时附上固定版本安装来源、校验值和完整指南，外部 AI 无需依赖 Nook 工具取得安装依据。剪贴板失败展开可手动复制的文本。指南按工具可用性选择 Host 工具或引导目标设备手动配置，按本次范围分别验收服务、接入和实际同步。

部署 skill 随 `feature-agent` 包分发，由指南工具读取构建时生成的指南与固定安装摘要，不依赖仓库路径或用户先安装 skill。指南只保留配置流程、产品契约和必要的数据保护要求；特定系统故障、代理探测、SSH 沙箱和数据锁恢复经验不随配置提示词分发，历史证据保留在实录。部署归档和助手文本以 LF 生成，使 Windows 工作区与 Linux 发布产物一致；公开 Linux 版本内容没有变化。

## Alternatives considered

**通过环境扫描判断用户需求。** 本机同步禁用且没有地址只说明本机尚未接入，不能证明没有服务器。扫描 SSH 历史和部署痕迹会延迟接入并可能选错目标，因此需求不明时先直接询问，环境检查限定在已选路径。

**只修改提示词开头。** 原指南仍默认家庭服务器、SSH 和当前 Host 接入，会把通用请求带回固定流程，因此入口、任务说明与指南一起调整。

**仅提供 Nook 工具名称供外部 AI 使用。** 外部 AI 未必具备这些工具，因此复制内容附带完整指南和安装依据，工具仅作为可用时的执行路径。

**让 AI 通过浏览器粘贴密码。** 它依赖可连接浏览器、文件选择器和页面结构，且容易把凭据带入对话。专用工具直接在 Host 读取文件，浏览器保留手动导入作为用户入口。

**直接写 settings.json。** 这会绕过备份、目标绑定及网络验证，且不能证明运行中的 Host 已应用设置，因此导入复用 Feature 方法。

**点击即自动发送提示词。** 用户需要先确认执行范围和补充目标信息，因此按钮只创建新的草稿，不提交模型请求，也不覆盖原会话输入。

**仅更新部署文档。** 文档不能消除 Host 配置导入的人工环节或修复跨平台摘要差异，因此同时交付工具、入口和打包修复。

## Validation

验收覆盖目标不匹配在联网前拒绝、无效和超大文件、取消、凭据不进入工具结果、真实备份及首次同步、工具卸载、独立草稿、LF/CRLF 产物一致性；完整 Profile 和打包验收检查指南与 skill 交付以及浏览器入口。具体运行结果更新于实录。

通用配置验收通过类型检查、构建、契约与同步导入集成测试、文档和包边界检查，以及完整 Profile 组成检查。干净安装验收通过 35 个 Nook 包、25 个 Profile 贡献和真实浏览器流程，覆盖未配置时直接打开 AI、指南草稿与复制内容一致、剪贴板拒绝后的手动复制回退。官方编辑器将每行渲染为段落，浏览器文本比较归一化展示产生的额外换行。

指南精简验证通过类型检查、构建、现有草稿与打包指南契约测试、格式和文档检查；检查 `feature-agent` 与 `ui-notes` tarball，确认工具指南与源文件一致，Client 同时包含新任务说明和指南，已删除的恢复经验没有进入产物。该检查验证内容分发，不代替模型在真实接入对话中的行为验收。

## Consequences

用户从按钮进入对话并发送后，AI 按确定的配置范围执行和验收，账号和操作系统的授权仍是交互边界。工具要求文件位于当前 Nook Host；远程浏览器电脑与 Host 不是同一机器时，不能混用路径。运行数据配置与源码开发验证分别隔离，既有用户改动不随此次工作提交。
