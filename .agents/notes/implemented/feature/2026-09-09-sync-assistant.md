# Agent Note: 家庭同步服务器安装助手

Status: implemented

## Problem

部署包上传、环境文件编辑、地址选择及连接文件下载要求用户理解多个工具，阻碍家庭服务器同步接入。已有服务验证与数据保护可以复用，但部署交接需要连贯的用户流程。

## Decision

独立 Python 助手配置宿主机依赖和固定摘要 Docker 服务，使用 Tailscale 身份自动确定地址，并以持久化回执保护重试和数据目标。systemd 控制首次启动顺序，Docker 仅处理已启动容器的失败重启。工具不访问 DSH Home，不改变 DSH 源码或第三方安装包。

助手与服务镜像独立版本化，安装入口、助手和部署归档逐层固定校验值。已公开的服务 0.1.0 多架构清单摘要通过 GHCR 匿名读取核实；其服务行为复用[镜像发布决策](2026-09-09-sync-container-release.md)，无需重发同名镜像。

界面默认显示家庭服务器引导，手动部署和 NAS 内容收纳在展开项中。连接信息通过可复制的带版本前缀文本交接，复用现有连接 DTO 和严格解析器；粘贴仅填充表单，仍通过已有 Host 配置流程验证和备份。该入口补充[系统安装与文件导入](2026-09-09-sync-server-setup.md)，不移除旧部署方式。

备份在停止写入后使用只读数据卷生成源文件摘要，逐文件验证归档；失败阻断更新，恢复服务。程序升级失败只回退程序选择，不自动覆盖业务卷。维护约束与验证边界由[工具契约](../../../../scripts/sync-server/README.md#安装助手约束)承载，路径和支持矩阵以[助手源码](../../../../scripts/sync-server/assistant.py)为准。

## Alternatives considered

**只提供 curl 下载 Compose。** 它仍需要编辑环境变量、导出文件和理解维护命令，无法满足用户对完整向导的要求。

**短配对码与远程凭据交换。** 需要额外的认证、限速、过期和凭据交换服务；复制完整配置可复用现有协议，不增加远端接口。文本携带密码，因此不会把编码描述为加密。

**默认 Tailscale Serve 反向代理。** 服务本身具有经过验证的 HTTPS 和 CA 导入支持，直接绑定 Tailscale IP 减少代理与证书管理分支。

**安装最新可变服务镜像。** 安装行为难以追溯，因此助手固定已核实的多架构摘要，更新由独立助手版本承载。

## Validation

验收覆盖重试、目标与降级拒绝、备份失败保护、摘要校验链、UTF-8 连接文本，以及粘贴不联网。隔离 Docker 验收执行真实服务安装、重复运行、备份逐文件校验、恢复到新测试卷和容器重建；Tailscale 登录和宿主机重启保留为实际部署验收边界。Debian 12 和 Ubuntu 24.04 的 arm64 一次性容器中，Docker / Compose / Tailscale 的官方软件源安装、依赖复用与 systemd 单元校验通过；发布工作流对 amd64 与 arm64 执行同一验收。

类型检查、构建、49 项契约及桌面测试、18 项集成测试、完整与 Safe UI 浏览器验收，以及 35 个干净安装包和 25 项 Profile 组合通过校验。安装助手另有 14 项失败与重试测试；真实 Docker 验收确认逐文件备份、全新测试卷恢复和重建后凭据不变。生成的一行命令在 Linux 容器中实际执行，验证 root 无 sudo 的入口及两级下载篡改拒绝。

## Consequences

跨平台构建统一 gzip 的操作系统头字段为 Linux 值，避免 macOS 界面嵌入的归档摘要与 Linux 发布产物不同。公开发布后对全部六个下载文件执行本地逐字节摘要对比，验证完整的安装命令校验链。

用户操作集中为服务器执行命令、Tailscale 授权和客户端粘贴连接信息。安装需要发布产物可达；本地构建或工作流文件存在不等于下载链接已经上线。备份保存在本机，用户仍需将其复制到独立介质。
