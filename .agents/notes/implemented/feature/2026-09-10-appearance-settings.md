# Agent Note: 外观主题、全屏设置与工具市集

Status: implemented

## Problem

工作台只有单一纸感主题，缺少适合夜间阅读的配色。同步与独立工具直接占据侧栏底部，设置入口和工具入口没有统一层级。

## Decision

保留默认纸感主题，增加 Claude 暖纸、夜晚与孟菲斯三套完整语义 tokens。暖纸以米白和陶土色组织层次，夜晚采用炭灰与暖白；编辑正文使用主题阅读字体。孟菲斯以浅蓝底、嫩黄按钮、浅粉凹陷面与亮蓝强调色营造青春亮丽的氛围，并使用更大圆角。预览卡片也使用真实 tokens，避免第二份调色板。偏好及界面契约见 [UI 包规范](../../../../docs/ui-packages.md)。

设置使用 Base UI Dialog 的全屏左右布局，左栏固定列出外观和数据同步，右栏承载面板。颜色仅作用于 Nook 自有工作区及其 Portal 后代，不修改宿主 DOM 或宿主主题。装配继续使用已核实的 `shell.overlay`，无新增 DSH 契约。

同步状态轮询保留在持续挂载的控制组件中，设置关闭或切换外观时不停止轮询；事件与请求随工作区卸载清理。配置指南继续使用已有独立视图，返回时恢复同步配置。数据同步协议、备份与冲突处理不变。

工具市集通过两个工具卡片启动既有视频与总结弹窗，复用原有编辑保存导航保护。设置可以临时覆盖编辑器而不卸载笔记，关闭后继续编辑。

该决定扩展 [UI Kit](2026-09-10-nook-ui-kit.md)，并调整[同步面板布局](../simplification/2026-09-09-sync-settings-layout.md)的容器层级。

## Alternatives considered

直接替换原纸感色卡会移除已有视觉选择，因此保留默认并新增可选主题。引用宿主主题会使 Nook 外观受另一套偏好控制，因此使用独立的语义变量作用域。

将同步组件仅挂载在活动面板中会中断笔记变更轮询，因此只切换可见内容，控制组件保持挂载。另建设置路由会增加导航与编辑状态交接，现有可访问弹窗足以承载全屏界面。

## Consequences

颜色仍只有一个来源，主题覆盖按钮、编辑器和浮层。设置新增分类可沿用左栏和右侧内容结构。窄屏保留左右导航，内容区域独立滚动；工具入口通过市集集中呈现。

## Validation

浏览器验收通过四套主题切换、偏好刷新保留、全屏尺寸、窄屏宽度、Esc 仅关闭设置、工具入口与完整同步配置流程。桌面明暗主题、390px 外观与同步配置截图经检查。类型检查、构建、91 项契约及桌面测试（另 1 项平台跳过）、20 项集成测试（另 2 项平台跳过）、颜色和依赖边界门禁、文档检查通过。干净安装验证 37 个打包包、25 个 Profile 行和真实 Host 浏览器全流程。

测试需要本地监听端口，在允许监听的环境执行；集成验证使用规范化临时目录避开 macOS 路径别名断言。开发隔离 Profile 的 AI 配置交接因标准 Agent 预设的五个包无法解析而失败，原因尚未定位；干净打包 Profile 的同一流程通过。全部运行时验证使用临时 DSH_HOME，不接触真实用户 Home。
