# Agent Note: 日周总结的模型失败反馈

Status: implemented

## Problem

日周总结失败时只显示“操作未完成，请重试。当前输入会保留。”，用户无法区分模型配置、连接与输出长度问题。生成适配器把所有非正常结束统一抛成普通错误，RPC 又隐藏普通错误消息；服务商提供的失败分类在两层处理中丢失。

用户指定 DeepSeek V4 Flash · OpenCode Go 后，使用相同配置和合成文本的在线诊断复现 HTTP 400：服务端要求请求携带会话标识。总结调用没有传入 DSH 的可选 `sessionId`，官方适配器因此不发送原生会话头。

## Decision

Generation Capability 定义携带安全提示的 `GenerationError`，DSH 适配器按[已核实的流结束契约](../../../../packages/adapter-intelligence-dsh/README.md#流结束与会话归因)把模型失败分类转换成 Nook 提示，RPC 允许该错误通过。认证、额度、限流、上下文、网络与输出长度分别提示。未识别错误保留模型配置与切换建议，不猜测具体原因，也不传递原始服务商响应。

生成在流结束后再次检查取消信号，避免最后一个数据块之后发生的取消返回成功正文。只有正常结束的非空正文能成为预览。产品行为见[笔记契约](../../../../packages/feature-notes/README.md)。

Generation 请求接受 Nook 自有字符串 `sessionId`，适配器把它传入官方模型请求；未分组调用得到独立的随机标识。总结 Feature 为每次总结创建标识，分批处理和最终合并共享它。标识不使用笔记内容，不需要创建或保存 DSH Session。

## Alternatives considered

在 RPC 直接展示所有异常消息：会让原始服务商响应、请求内容或凭据进入界面，且不能恢复生成适配器已经丢弃的错误分类。

增加输出长度上限或自动重试：在线诊断明确指出缺少会话标识，修改长度上限或重复相同请求无法解决该错误。

修改官方适配器或自行注入 OpenCode 专用 HTTP 头：官方适配器已支持服务端认可的原生会话头，传入公开请求字段即可，避免维护额外网络适配或触碰安装包。

## Validation

[智能流程测试](../../../../tests/contract/intelligence.test.ts)通过真实 DSH LLM Runtime、测试模型适配器、总结 Feature 和严格 Gateway 验证失败提示、HTTP 状态回退、目录读取失败、不完整输出拒绝、取消、重试成功以及原笔记与数量不变。测试模型不访问外部服务，不能证明用户所选模型的实际可用性。

同一回归测试验证所有生成请求带会话标识、分批总结共享标识、独立总结相互隔离，以及调用方标识透传。在线验收只使用临时数据库中由助手编写的合成笔记，不读取用户笔记。

相同 OpenCode Go 模型、端点和 6000 token 输出上限下，补齐会话标识的真实总结流程返回 429 字正文及一条来源引用，临时数据库仍只有原始合成笔记，未自动写入总结。该结果验证本次缺失会话标识的根因与修复，不代表任意模型或服务商均可用。

类型检查、构建、文档与包边界检查、Profile 组合检查通过。53 项契约及桌面测试、18 项集成测试全部通过。全新安装包验证覆盖 35 个包、25 个组合条目和浏览器验收。

## Consequences

总结失败具有可操作的提示，并保持 Capability 与 DSH 的边界。服务商原始文本不进入 RPC；未知模型故障仍需要进一步获取运行环境信息，不能仅凭通用错误推断网络、额度或配置问题。
